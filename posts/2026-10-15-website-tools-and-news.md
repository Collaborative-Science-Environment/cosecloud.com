Two small additions to the site.

**Tools.** The run analysis page from software 1.3.0 is now hosted at [cosecloud.com/tools](/tools/), so it can be opened from any computer without copying the file from a run folder. It works exactly as the local copy does: drop a run's `imu.csv` on it and everything is computed in your browser; nothing is uploaded. One difference: served from the web, most browsers will let you drop the whole run folder rather than picking out the files. The hosted copy is always the current version, and the version number is in its footer.

**News.** Software releases, new instruments and deliveries will be posted here, with an [RSS feed](/posts/feed.xml) for anyone who prefers to be told. Release notes for 1.3.0 are the first entry.
